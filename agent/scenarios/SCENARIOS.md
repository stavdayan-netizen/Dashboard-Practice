# Scenario transcripts (mocked model, free)

Generated by `agent\tests\Test-AgentScenarios.ps1` on every run. The assistant's words here are **scripted test text**: this file records what the **server** does with them (guards, fixed safety messages, proposals, manager decisions, persistence), through the same HTTP routes the tenant portal and the dashboard use. It contains no ids, tokens, keys or timestamps. How the real model behaves is recorded only by the approved live tests (see `agent/FINAL_LIVE_TEST_PLAN.md`).

## S1. An ordinary request, a follow-up, and the manager approving the proposal

A tenant submits a dishwasher problem. The assistant replies on its own, drafts a routine proposal, the tenant answers a question, the manager approves and marks the proposal applied. The server never changes the ticket itself.

**What the tenant sees**

- Tenant: My dishwasher is not draining and there is water standing in the bottom.
- Assistant: Hi! I am your AI Maintenance Assistant. Please run the kitchen sink for about 30 seconds. Does the water drain normally?
- Tenant: The sink drains fine.
- Assistant: Thanks. Since the sink drains well, the dishwasher itself is the likely cause. Please wait about 20 minutes after your last cycle before looking at the filter. Is the dishwasher running right now?

**What the manager sees**

- Proposal [applied] ai_handling_status=Waiting for Tenant; ai_urgency=Routine; notes=Tenant reports the dishwasher is not draining; the water stands in the bottom.. Why: New report: dishwasher not draining, water contained inside the appliance. (reply check: clean (model))

**Checks**

- pass: a submitted request becomes a new demo ticket and the assistant replies without the tenant typing anything
- pass: the transcript is request, reply, answer, reply
- pass: exactly one pending proposal was drafted
- pass: the manager approves the proposal
- pass: approving changes nothing on the stored ticket (priority and status untouched)
- pass: a second decision on the same proposal is refused (409)
- pass: the tenant's original text is kept whole, the short label is a piece of it, and no summary was written by the assistant's conversation
- pass: the manager side marks an approved proposal as applied
- pass: marking it applied twice is refused (409)
